About MinutesMap

MinutesMap is a live basketball visualization dashboard built to make play-by-play data easier to follow in real time. It combines a high-density timeline view with game context so you can see how lineups, runs, and key events unfold.

The app is focused on speed and clarity, with real-time updates and a lightweight interface that works well on desktop and smaller screens.
